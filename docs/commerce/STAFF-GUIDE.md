# Checking a missing parcel

You need a web browser and the sign-in details provided by your store's manager.
You do not need coding knowledge, an AI agent, or any command-line tools.

1. Sign in and select the customer's order.
2. Choose **Start review**. The store checks payment, delivery, stock, refunds
   and its replacement rules automatically. You can return later if it is busy.
3. Read **What to do next** and **Order checks**.
   - **Confirmed** means that check passed.
   - **Not met** explains a reason the replacement is unavailable.
   - **Needs information** means something has not been confirmed. It does not
     mean the customer is wrong or that the requirement failed.
4. If a replacement is available, review its items, sizes and quantities.
   Choose **Approve replacement**, then confirm. Approval alone does not create it.
5. Choose **Create replacement**, then confirm. Wait for **Replacement confirmed**.
   The items are set aside; they have not been shipped yet.

If information changes while you review, refresh the case and review the new
information before approving again. Do not assume a late parcel is lost unless
the carrier confirms it.

If you are unsure, add a note under **Need help?** and choose **Ask for help**.
This saves your note and marks the case for review. Tell your manager the order
reference and what needs checking; the demo does not send them a notification.

If the store is temporarily unavailable, try again in a moment. If it continues,
ask your manager for help. If a replacement result needs confirmation, have your
manager check the existing case before creating another replacement.

Technical details are for support. You can complete the normal workflow without
opening them. This is a demo store: it does not make real payments or shipments.
